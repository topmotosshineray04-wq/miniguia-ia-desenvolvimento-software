# 📖 Glossário de Conceitos Fundamentais

| Termo | Definição |
| :--- | :--- |
| **Inteligência Artificial (IA)** | Campo da computação focado em sistemas que simulam capacidade cognitiva humana. |
| **IA Generativa (GenAI)** | Modelos treinados para criar conteúdos inéditos (texto, código, imagem). |
| **LLM (Large Language Model)** | Modelos de linguagem de grande escala para processar texto e código. |
| **Prompt** | Instrução ou contexto fornecido para guiar a resposta da IA. |
| **Engenharia de Prompt** | Técnica de estruturar instruções para obter respostas precisas. |
| **Alucinação** | Respostas falsas geradas pela IA com aparência de certeza. |
| **RAG (Retrieval-Augmented Generation)** | Técnica usada pelo NotebookLM para ancorar a IA em documentos específicos. |
| **Human-in-the-Loop (HITL)** | Princípio da necessidade de validação humana nas saídas da IA. |
| **NIST AI RMF** | Framework oficial para gestão de riscos em IA. |
| **Token** | Menor unidade de texto processada por um modelo de linguagem. |
